# Игра в пары

Игровой процесс очень простой. Вы переворачиваете карточку, а затем пытаетесь найти ей пару. Лимит времени: 30 секунд. Перед началом игры Вам необходимо выбрать количество пар. Значение должно быть чётным. По умолчанию — четыре пары карт.

## Запуск

Проект использует ES-модули, поэтому его нужно открыть через локальный статический сервер (например, `python -m http.server 8000`), а не напрямую из файловой системы.

## Архитектура

Код разделён на слои чистой архитектуры с зависимостями, направленными внутрь:

- `js/domain` — сущности и игровая логика (`Card`, `Deck`, `Game`, `GameStatus`), не зависящие от браузера;
- `js/application` — сценарии использования (`StartGame`, `FlipCard`, `FinishGame`, `RestartGame`) и абстрактные порты (`Timer`, `GameOutput`);
- `js/interfaces` — адаптеры: представление (`SetupView`, `BoardView`), presenter, контроллер и браузерный таймер;
- `js/main.js` — композиционный корень, связывающий все слои.

## Использованные технологии:
