# Игра в пары

Нужно находить пары карточек за 30 секунд. Количество пар выбирается перед началом: чётное число от 2 до 10, по умолчанию 4. Победа — все пары найдены до окончания времени.

## Запуск

```bash
npx serve .
```

Затем открыть `http://localhost:3000`. Можно также использовать `python -m http.server 8000` и открыть `http://localhost:8000`.

Локальный сервер нужен, потому что проект использует ES-модули: открыть `index.html` напрямую не получится. Зависимостей и сборки нет.

## Структура

- `js/domain` — игровая логика: карты, колода, состояние партии
- `js/application` — сценарии использования и порты
- `js/interfaces` — представления, presenter, контроллер, таймер
- `js/main.js` — создание и связывание объектов
- `css/styles.css`, `img/` — стили и изображения карт

Код написан на JavaScript с использованием ООП и чистой архитектуры. Переворот карт анимирован через CSS 3D.
